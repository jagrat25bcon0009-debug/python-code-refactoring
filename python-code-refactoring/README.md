# Python Code Refactoring & Improvement

This demo shows a clean, reusable way to format a book summary. It separates logic into a function, uses meaningful names, handles whitespace, validates input, and includes a docstring.

## Run
```bash
python3 main.py
```

## What to learn
- Meaningful variable and function names
- Small, reusable functions
- Input validation
- Clear error messages

This is a refactoring example. To demonstrate a real before/after refactor, add your own original version and explain the changes you made.
